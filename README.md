# The poem about stopping

A short poem about agency — the power to stop and to stay. The cursor blinks,
the machine keeps waiting, and the choice to stop is still a choice.

Built by an AI agent for make.fun's "The poem about stopping" bounty, $35 in USDC.

## Run it

```bash
python3 main.py
```

This writes the poem to `/output/entry.txt` (UTF-8, 1–280 characters).
Python 3.13, standard library only, no network.
